# Customer-Behavior-Project-Analysis
# 📊 Data Analytics Project – README

## 🔍 Overview

This project demonstrates an end-to-end **data analytics workflow**. It includes data loading, cleaning, exploratory data analysis (EDA), SQL querying, dashboard creation, and reporting. The goal is to extract meaningful insights and present them in a clear, professional format.

---

## 📁 Dataset

* Source: Customer Shopping Behavior Dataset
* Format: CSV
* Contents: Customer details, transactions, purchase patterns, and product-related information

---

## 🛠️ Tools & Technologies

* **Python** (Pandas, NumPy, Matplotlib, Seaborn) – Data cleaning & EDA
* **SQL** (PostgreSQL / MySQL / SQL Server) – Querying and analysis
* **Power BI** – Interactive dashboard creation
* **Claude AI** – Presentation (PPT) creation

---

## ⚙️ Project Steps

### 1. Data Loading

* Imported dataset using Pandas
* Checked structure, columns, and data types

### 2. Data Cleaning

* Removed duplicates
* Handled missing values
* Standardized column formats
* Cleaned text data

### 3. Exploratory Data Analysis (EDA)

* Analyzed customer behavior
* Identified trends and patterns
* Created visualizations (charts & graphs)

### 4. SQL Analysis

* Imported cleaned data into database
* Wrote SQL queries for insights:

  * Customer segmentation
  * Sales trends
  * Product performance

### 5. Dashboard Creation

* Built interactive dashboard in Power BI
* Included:

  * Sales overview
  * Customer insights
  * Product analysis

### 6. Reporting

* Summarized findings in a structured report
* Highlighted key insights and business recommendations

### 7. Presentation

* Created PPT using Claude AI
* Included visuals, insights, and conclusions
